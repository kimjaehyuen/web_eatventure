# 맛집 원정대 (web_eatventure)

모바일 방치형 식당 게임 Eatventure에서 영감을 받은 팬메이드 웹 게임입니다. 원작의 이름이나 그림 리소스는 쓰지 않았고, 클랜 시스템은 넣지 않았습니다.

## 실행 방법

빌드 과정이 없는 HTML 파일 하나짜리 게임입니다. `index.html`을 브라우저로 열면 바로 할 수 있습니다.
GitHub Pages(Settings → Pages → `main` 브랜치 루트)를 켜면 웹 주소로도 공유할 수 있습니다.

## 게임 방법

- 손님이 주문하면 셰프가 조리대에서 요리해서 가져다줍니다.
- 조리대를 누르면 레벨을 올릴 수 있습니다(x1 / x10 / MAX). 레벨 10·25·50·75·100에서 속도나 수익 보너스가 붙습니다.
- 요리 중인 조리대를 톡톡 누르면 셰프가 더 빨리 만듭니다.
- 조리대 6개를 차례로 열고 업그레이드 15개를 모두 사면 다음 도시로 이동합니다(버거 → 초밥 → 피자 → 타코 → 디저트, 이후 더 높은 배율로 반복).
- 보석으로 상자를 열어 장비 카드 8종을 모읍니다. 장비 효과는 도시를 옮겨도 유지됩니다.
- VIP 손님(5배 결제), 러시 아워(2분간 수익 2배), 10분마다 무료 보석, 오프라인 수익(최대 2시간)이 있습니다.

진행 상황은 브라우저 localStorage에 자동 저장됩니다.
